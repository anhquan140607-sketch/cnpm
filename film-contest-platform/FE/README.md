#  Giao Diện Nguyên Mẫu Frontend (FE UI Mockups)

Thư mục này chứa các bản thiết kế giao diện nguyên mẫu (HTML/CSS tĩnh) dùng để tham chiếu cho các phân hệ chức năng quan trọng của **Nền tảng Quản lý Cuộc thi Nhiếp ảnh Phim**. 

Các file HTML ở đây mô phỏng luồng trải nghiệm người dùng (UX) và cấu trúc giao diện (UI) trước khi được tích hợp vào framework chính (React/Next.js).

---

##  Danh Sách Các Trang Giao Diện (Page Index)

* 📄 **[negative-contact-sheet-manager.html](./negative-contact-sheet-manager.html)**
  * **Mô tả:** Giao diện Không gian làm việc (Workspace) dành cho Thí sinh để tải lên và quản lý cuộn phim (Film Rolls), bản scan âm bản (Negatives) và bản phơi sáng tổng hợp (Contact Sheets). Hỗ trợ tính năng chọn lọc (select/crop) từng khung hình (frame) dự thi.

* 📄 **[submission-management-system.html](./submission-management-system.html)**
  * **Mô tả:** Giao diện Hệ thống quản lý bài nộp. Dành cho Thí sinh (để theo dõi trạng thái, chỉnh sửa hoặc rút bài) và Ban tổ chức (để duyệt, lọc và phân bổ bài nộp cho Giám khảo).

* 📄 **[test-case-management-dashboard.html](./test-case-management-dashboard.html)**
  * **Mô tả:** Dashboard (Bảng điều khiển) dành cho đội ngũ QA/Tester để theo dõi, quản lý tiến độ chạy các kịch bản kiểm thử (Test Cases), báo cáo lỗi (Bugs) và thống kê tỷ lệ bao phủ của quá trình kiểm thử phần mềm.

---

##  Hướng Dẫn Sử Dụng
* Các file trong thư mục này có thể được mở và xem trực tiếp bằng bất kỳ trình duyệt web nào (Chrome, Edge, Safari...) mà không cần cài đặt môi trường server cục bộ.
* Nhấp đúp chuột vào file `.html` hoặc kéo thả file vào trình duyệt để trải nghiệm luồng giao diện.
