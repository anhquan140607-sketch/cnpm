# Skills

Reusable instruction files for the team, one file or subfolder per skill. Typical content:

- A prompt or checklist for repeated work (for example, writing a Jira story, reviewing a pull request, writing a test case).
- Steps for a repeated technical task (for example, running the backend locally, seeding master data).

Suggested layout:

```
Skills/
├── README.md
├── review-pull-request.md
└── write-jira-story.md
```

Rules:

- One skill per file, in Markdown, with a short title and numbered steps.
- Add new skills through a pull request like any other file.
