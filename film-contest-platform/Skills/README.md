## Quy tắc đóng góp Skill mới:
- Mỗi skill được viết thành 1 file Markdown riêng biệt, có tiêu đề ngắn gọn và các bước đánh số rõ ràng.
- Mọi tài liệu kỹ năng mới đều phải được đẩy lên qua Pull Request giống như mã nguồn dự án.
